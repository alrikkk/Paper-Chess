# Paper Chess 
# version 1.0

Hi , I built this chess game for the Stardance Challenge , I hope you like my game :) 

Paper chess is game with a little twist, the idea was to go for a paper-ish theme and i tired my best to do that and i think it turned out well ( ihope). I got board of looking at the same old wood board design and though this would be a fun project to ship.

I built this project as part of **Stardance**, focusing on making a classic chess game feel a bit more creative and fun to play.

## Features

- Play chess with a friend or against the bot.
- Custom paper-cutout chess pieces.
- Multiple themes, including the Brainrot theme.
- Custom sound effects and background music.
- Move history and captured-piece tracking.
- Adjustable settings and a custom game interface.

## Built With

- React
- TypeScript
- Vite
- Python
- FastAPI
- python-chess

## Running Locally (if you want to)

Clone the repository:

```bash
git clone https://github.com/alrikkk/Paper-Chess.git
cd Paper-Chess
```

Install the frontend dependencies:

```bash
npm install
```

Start the frontend:

```bash
npm run dev
```

The Python backend is located in the `backend` folder. Install its dependencies using:

```bash
cd backend
pip install -r requirements.txt
```

Start the backend:

```bash
uvicorn main:app --reload
```

## A Note

This project started as a simple idea to make chess feel different. A lot of the experience went into the little details — the pieces, the sounds, the themes, and the overall look of the game.

Thanks for checking it out!
