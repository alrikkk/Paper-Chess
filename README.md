# Paper Chess 
# version 1.0

Hi , I built this chess game for fun cause i got bored with standar board chess games, I hope you like my game :) 

Paper chess is game with a little twist, the idea was to go for a paper-ish theme and i tired my best to do that and i think it turned out well ( ihope). I got bored of looking at the same old wood bored design and thought this would be a fun project to ship.

I built this project as part of **Stardance**, focusing on making a classic chess game feel a bit more creative and fun to play with brainrot ;) idk personal suggestion.

## Features

- Play chess with a friend or against the bot.
- Paper-cutout chess pieces.
- Multiple themes, including the Brainrot theme.
- Sound effects and background music.
- Move history and captured-piece tracking.
- Adjustable settings and a custom game interface.

## Built With

- React
- TypeScript
- Vite
- Python
- FastAPI
- python-chess

## Running Locally (if you want to)

Clone the repository:

```bash
git clone https://github.com/alrikkk/Paper-Chess.git
cd Paper-Chess
```

Install the frontend dependencies:

```bash
npm install
```

Start the frontend:

```bash
npm run dev
```

The Python backend is located in the `backend` folder. Install its dependencies using:

```bash
cd backend
pip install -r requirements.txt
```

Start the backend:

```bash
uvicorn main:app --reload
```
